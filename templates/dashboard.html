Recommended Workflow

  1. Import the client's FAR.
  2. Capture/verify assets physically in each location.
  3. Record tag, serial, model, user and custodian.
  4. Mark condition and verification status.
  5. Run reconciliation and investigate differences.
  6. Export the final field register.

Field Capture Standard

Minimum identification: Asset Name + Tag Number or Serial Number.

Accountability: Location + User + Custodian.

Audit evidence: Condition + Remarks. Production version can add photographs, GPS and timestamps.
